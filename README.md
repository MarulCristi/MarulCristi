## Selected work

| Project | What I built | Stack |
|---|---|---|
| [**CloudDrive**](https://github.com/MarulCristi/CloudDrive) | A collaborative document editor and file manager with sharing, comments, authentication, multilingual UI, import/export, and a FIFO real-time editing-lock system. | React, TypeScript, Node.js, Express, MongoDB, Material UI |
| [**Country Battle Royale**](https://github.com/MarulCristi/country-battle-royale) | An interactive country-ball battle simulator with Canvas-powered selectors, animated combat, persistent rankings, access tiers, and server-side key validation. [Live demo](https://country-battle-royale.netlify.app) | Vanilla JavaScript, HTML, CSS, Canvas, Netlify Functions |
| [**StatSuomi**](https://github.com/MarulCristi/StatSuomi) | An interactive Finnish municipal statistics dashboard that turns live PxWeb datasets into maps and configurable charts. [Live demo](https://marulcristi.github.io/StatSuomi/) | JavaScript, Statistics Finland API, maps, data visualization |
| [**ShushNet**](https://github.com/MarulCristi/ShushNet-distributed-systems) | A distributed apartment-complaints platform with a central broker, manager and tenant flows, real-time notifications, and a shared complaints model. | React, TypeScript, Express, Socket.IO, MongoDB, npm workspaces |
| [**Energy Data Analyzer**](https://github.com/MarulCristi/energy_scala_project) | A functional-programming project for fetching, parsing, filtering, analyzing, and monitoring energy records. | Scala, STTP, uPickle, sbt |
